# Who Chop My Data?

A single-file browser game. No build step, no dependencies, no server code.

## Deploy
Upload `index.html` to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any web server).
Serve it over HTTPS so sharing and vibration work on phones.

## Notes
- Progress (naira, upgrades, best week, badges) is saved in the player's browser localStorage under the key `wcmd3`.
- The share button uses the page URL, so deploy to your final domain before sharing.
- The game is portrait-first and works offline once loaded.
